# Мир ступеней

Сайт-визитка мастерской лестниц в Кемерово. Адаптивная статическая страница, без внешних зависимостей и сборки.

## Локальный запуск

Из корня репозитория:

```sh
python3 -m http.server 3000 --bind 0.0.0.0
```

Для проверки сервера выполните `curl --fail http://127.0.0.1:3000/` в другом терминале. Развёртывание возможно на любом хостинге статических файлов с HTTPS.

## Перед публикацией

- Добавить реальные фотографии работ с разрешением владельца. Текущие SVG и схемы — иллюстрации, а не портфолио.
- Добавить подтверждённый телефон и ссылки на мессенджеры в блок контактов.
- Подтвердить материалы, порядок работы и сведения об услугах с владельцем.
- Бриф формирует текст только на устройстве посетителя; серверной отправки заявок нет. Данные никуда не передаются и не сохраняются сайтом.

Основная страница — `index.html`, оформление — `style.css`, меню и бриф — `script.js`.

## Варианты оформления

Над шапкой страницы расположен переключатель пяти расцветок: исходный вариант, «Графит и медь», «Белый и синий», «Изумруд и золото», «Песок и олива». Прямой выбор через адрес: `index.html?theme=dark`, `?theme=light`, `?theme=emerald` или `?theme=sand`.

Для простого просмотра есть четыре автономных файла: `variant-graphite.html`, `variant-blue.html`, `variant-emerald.html` и `variant-sand.html`. В них встроены стили, скрипты и иллюстрации: достаточно открыть один файл в браузере. Макеты находятся в `previews/`.

Основные правки вносите в `index.html`, `style.css`, `themes.css`, `script.js` и `assets/`. После изменения этих файлов обновите автономные версии командой `python3 tools/build_variants.py`. Для обычного запуска сайта генерация не требуется.
