# Мир ступеней

Сайт-визитка мастерской лестниц в Кемерово. Адаптивная статическая страница, без внешних зависимостей и сборки.

## Локальный запуск

Из корня репозитория:

```sh
python3 -m http.server 3000 --bind 0.0.0.0
```

Для проверки сервера выполните `curl --fail http://127.0.0.1:3000/` в другом терминале. Развёртывание возможно на любом хостинге статических файлов с HTTPS.

## Перед публикацией

- Добавить реальные фотографии работ с разрешением владельца. Текущие SVG и схемы — иллюстрации, а не портфолио.
- Добавить подтверждённый телефон и ссылки на мессенджеры в блок контактов.
- Подтвердить материалы, порядок работы и сведения об услугах с владельцем.
- Бриф формирует текст только на устройстве посетителя; серверной отправки заявок нет. Данные никуда не передаются и не сохраняются сайтом.

Основная страница — `index.html`, оформление — `style.css`, меню и бриф — `script.js`.

## Оформление и автономная версия

Выбрано единственное оформление «Изумруд и золото»: изумрудный фон, светлый текст и золотистые акценты. Переключатель и альтернативные расцветки удалены. Актуальный макет находится в `previews/site.png`.

Для простого просмотра откройте `site.html`. В этот файл встроены стили, скрипты и иллюстрации: он не требует других файлов рядом. Основной сайт по-прежнему запускается через `index.html`.

Основные правки вносите в `index.html`, `style.css`, `script.js` и `assets/`. После изменения этих файлов обновите автономную версию командой `python3 tools/build_standalone.py`. Для обычного запуска сайта генерация не требуется.
