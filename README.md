## Обновление

Закрой старые тесты и скопируй новые файлы в папку программы с заменой. Сохрани `.venv` и `config.json`; повторный setup.bat не нужен. Новые зависимости не добавлялись.

## Тест команды Spoil

1. Выбери живого Ghoul или Dead Seeker рядом, которого ещё не спойлил.
2. Запусти **test_spoil_command.bat от имени администратора**.
3. За 10 секунд вернись в LU4 и **открой пустую строку ввода игрового чата**. Удали прежний текст, если он остался. Саму команду вводить не нужно. Цель должна оставаться выбранной.
4. Оставайся в игре около 20 секунд, отпусти Alt/Ctrl/Shift/Win. Программа введёт `/useskill Spoil` и один раз нажмёт Enter. Esc после команды не отправляется.
5. Пришли `runs/controls-test-…jsonl` и результат: применился ли Spoil, остался ли текст в строке ввода или появилась ошибка команды. Если текст не появился, так и напиши.

В консоли должны быть версия **0.3.1** и строка **SPOIL CHAT COMMAND**. В этом тесте не нужно переставлять навыки на панели, менять config.json или самостоятельно отправлять команду. Он не зависит от назначения Spoil на F2/F3.

Текст отправляется через стандартный Win32 SendInput с Unicode-символами; Enter — скан-кодом. При потере фокуса до отправки Enter набор прекращается без отправки команды. F9 останавливает тест и отпускает удерживаемую клавишу; при остановке во время набора часть команды может остаться в чате — её следует удалить вручную. Если Enter уже отправлен, отменить применённую способность этим тестом нельзя.

Чат нужно открыть заранее: тест не определяет состояние строки ввода и не очищает её. Журнал фиксирует принятые Windows события, а не появление текста и применение навыка в игре. Атака, подбор, чтение памяти игры и повторение команды в этот тест не входят.

## Остальные режимы

- `run.bat`: наблюдение, OCR имени/HP цели и HP/MP персонажа, калибровка областей и экспорт ZIP диагностики. Основной Observer не управляет персонажем.
- `test_spoil_f3.bat` и `test_spoil_only.bat`: прежняя проверка одной F3 с последующим Esc. Она не запустила Spoil у пользователя; повторять её для нового теста не требуется.
- `test_controls_scan.bat`: одна F2. Действие определяется назначением F2 в самой игре.
- `test_one_cycle.bat`: экспериментальная последовательность F3 → F1 → подтверждение смерти → F4 → F5. Она пока не переведена на команды чата; запуск навыков программными F-клавишами в клиенте не подтверждён.
- Старый мышиный тест отключён после изменения расположения навыков.

Настройки программы для панели: F1 атака, F2 следующая цель, F3 Spoil, F4 Sweep, F5 подбор, F6 резерв. Они не меняют назначения внутри LU4. Точная старая стандартная раскладка F1/F2/1/2/5 при чтении переводится в новую, другие параметры и исходный файл сохраняются. Нестандартные пользовательские привязки не перезаписываются. Тест команды этих назначений не использует.

Автопоиск, повторение фарма, восстановление и возврат к точке пока не реализованы. Журналы и кадры сохраняются локально без автоматической отправки.
