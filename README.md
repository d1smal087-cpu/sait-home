# Мир ступеней

Сайт-визитка мастерской лестниц в Кемерово. Адаптивная статическая страница, без внешних зависимостей и сборки.

## Локальный запуск

Из корня репозитория:

```sh
python3 -m http.server 3000 --bind 0.0.0.0
```

Для проверки сервера выполните `curl --fail http://127.0.0.1:3000/` в другом терминале. Развёртывание возможно на любом хостинге статических файлов с HTTPS.

## Публикация через GitHub Pages

Файлы подготовлены для публикации без сборки: `index.html` находится в корне, все ресурсы используют относительные пути, `.nojekyll` отключает обработку Jekyll.

Для первого включения откройте `https://github.com/d1smal087-cpu/sait-home/settings/pages`. В разделе Build and deployment выберите Source: **Deploy from a branch**, Branch: **main**, папка **/(root)**, затем **Save**. Дождитесь завершения публикации GitHub Pages. После включения новые изменения в `main` будут публиковаться автоматически.

Ожидаемый адрес после успешной публикации: `https://d1smal087-cpu.github.io/sait-home/`.

## Оформление и автономная версия

Выбрано единственное серо-оливковое оформление: основной фон `#6e6f5d` взят с образца владельца, текст светлый, акценты цвета шампанского. Переключатель и альтернативные расцветки удалены. Актуальный макет находится в `previews/site.png`.

Для простого просмотра главной страницы откройте `site.html`. В этот файл встроены стили, скрипты и фотографии главной. Для перехода в полный каталог нужны соседние `works.html`, папки `works/`, `assets/` и общие стили и скрипт. Основной сайт запускается через `index.html`.

Основные правки вносите в `index.html`, `style.css`, `script.js` и `assets/`. После изменения этих файлов обновите автономную версию командой `python3 tools/build_standalone.py`. Для обычного запуска сайта генерация не требуется.

## Обновление полного портфолио

`portfolio.json` хранит публичные названия объектов и относительные пути к подготовленным фотографиям. Секретов и временных ссылок загрузки в нём нет.

Для повторного импорта с публичного Диска требуется Python с Pillow и доступ к `cloud-api.yandex.net`, `downloader.disk.yandex.ru` и `*.storage.yandex.net`:

```sh
python3 tools/import_portfolio.py
python3 tools/build_portfolio.py
python3 tools/build_standalone.py
```

Импорт сохраняет только изображения, без метаданных EXIF; существующие файлы повторно не скачиваются. Если меняете шапку, подвал или разметку просмотрщика на главной, повторно запустите `tools/build_portfolio.py`, чтобы обновить их на страницах каталога. Для публикации и просмотра готового каталога Python и Pillow не нужны.
