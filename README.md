# LU4 Observer 0.3.0 — F-клавиши

**[Скачать ZIP для Windows — версия 0.3.0](https://github.com/d1smal087-cpu/sait-home/raw/refs/heads/lu4-observer/downloads/lu4-observer-0.3.0.zip)**

Раскладка программы переведена с обычных цифр на F-клавиши. Подтверждена программная F2; остальные действия ещё нужно проверить в игре.

| Клавиша | Действие |
| --- | --- |
| F1 | Атака |
| F2 | Следующая цель |
| F3 | Spoil |
| F4 | Sweep |
| F5 | Обычный подбор |
| F6 | Резерв, программа её не нажимает |

## Сначала настрой LU4

В самой игре перенеси соответствующие действия в слоты нижней панели F1–F5 или назначь эти клавиши в настройках управления. Особенно важно: Spoil должен запускаться через F3, Sweep через F4, а подбор через F5. В прежнем расположении F3 был занят другой способностью — замени назначение до запуска теста.

Настройки программы не меняют привязки внутри клиента. Проверь новую F3 вручную. Для программного теста затем выбери другого живого моба, которого ещё не спойлил.

## Обновление

Закрой старые тесты, скопируй новые файлы в папку программы с заменой. Сохрани `.venv` и `config.json`: установка библиотек не требуется. Стандартная старая раскладка F1/F2/1/2/5 в сохранённом config.json автоматически заменяется при чтении на новый набор, остальные области и параметры сохраняются. Пользовательские нестандартные привязки не перезаписываются; несовпадающий с F3 Spoil нужно исправить вручную.

## Один тест F3

1. Встань рядом с живым Ghoul или Dead Seeker и выбери его.
2. Запусти **test_spoil_f3.bat от имени администратора**.
3. За 10 секунд вернись в LU4, закрой ввод чата, отпусти Alt/Ctrl/Shift/Win. Цель должна оставаться выбранной.
4. Оставайся в игре 15 секунд. Программа попробует одну F3, через три секунды отправит Esc и закончит работу. Атаки и OCR в этом тесте нет.
5. Пришли свежий `runs/controls-test-…jsonl` и результат: применился ли Spoil, появилась ли анимация или расход маны.

В консоли должна быть версия 0.3.0 и строка **SPOIL F3 ONLY**. F9 отменяет ожидание. Удержание — 300 мс, скан-код F3 — 0x3D; активность LU4 и отсутствие модификаторов проверяются.

Старый `test_spoil_only.bat` тоже использует F3 после обновления, но основной файл для этой проверки — `test_spoil_f3.bat`. Мышиный тест отключён из-за изменённого положения навыков.

## Остальные режимы

- `run.bat`: наблюдение, распознавание имени/HP цели и HP/MP персонажа, настройка рамок мышью, экспорт ZIP диагностики.
- `test_one_cycle.bat`: экспериментальный один бой F3 → F1 → подтверждение смерти → F4 → F5. Используй после успешной проверки F3 и всех назначений. Работоспособность этого цикла в LU4 пока не подтверждена.
- Автопоиск, повторение фарма, восстановление и возврат к точке пока не реализованы.

При одном бое действуют пределы: HP не ниже 50%, MP не ниже 20%, бой до 30 секунд, отсутствие урона до 5 секунд. F9 прекращает действия программы и при активной игре пытается снять цель через Esc. Если переключиться в другую программу, начатую автоатаку игры нужно остановить вручную при возвращении.

Успех Spoil/Sweep и полнота подбора ещё не подтверждаются автоматически. Основной Observer не управляет персонажем. Журналы и кадры сохраняются локально, без автоматической отправки.

## Проверки и история

Из папки проекта: `.venv/Scripts/python.exe -m unittest discover -s tests -v`. Результаты — в [VALIDATION.md](VALIDATION.md). Старые диагностические шаги — в [истории версий](docs/previous-tests.md); их назначения клавиш устарели.

Для первой установки нужен Python 3.12 x64, затем setup.bat. Если среда уже установлена, повторный setup.bat не нужен.
