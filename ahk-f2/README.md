# Независимая проверка F2 — AutoHotkey v2 SendEvent

В повторном тесте точная старая версия 0.1.7 не выбрала цель. Журнал совпадает с прежним успешным запуском по всем записанным полям, кроме времени. Ошибка новой версии не объясняет результат. Пользователь предположил фильтрацию античитом; журнал SendInput не подтверждает и не опровергает эту гипотезу.

Этот отдельный тест использует AutoHotkey v2 и обычный SendEvent вместо Python SendInput. Он отправляет только одну пару F2 down/up (vk71/sc03C), удержание 300 мс. Это проверка альтернативного стандартного метода, не гарантия совместимости с клиентом. SendEvent тоже может не дать результата при фильтрации искусственного ввода.

## Запуск

1. Установи **AutoHotkey v2** с https://www.autohotkey.com/ (версия 1 не подходит). Если используешь портативную версию, положи AutoHotkey64.exe рядом с BAT и AHK.
2. Распакуй этот ZIP в отдельную папку. Observer и Python для теста не нужны. Закрой другие тесты, в том числе ранее запущенные копии AHK.
3. В игре F2 должна выбирать следующую цель. Встань возле видимого моба, закрой чат, сними выделение через Esc.
4. Запусти **test_ahk_f2.bat от имени администратора**, за 10 секунд вернись в LU4, отпусти модификаторы и подожди 15 секунд.
5. Пришли runs/ahk-f2-…jsonl и сообщи, выбралась ли цель. Если вместо запуска возникла ошибка AutoHotkey, пришли её текст.

F9 отменяет ожидание и удержание. Перед нажатием проверяются повышенные права, активный LU4/UnrealWindow и отсутствие модификаторов; в течение удержания проверяются отмена и фокус. При ошибке/отмене всегда делается попытка отпустить F2. Esc, навыки, мышь, команды чата и повторное нажатие не отправляются.

Журнал показывает вызовы SendEvent, а не принятие нажатий игрой. Эффект в LU4 требует пользовательского подтверждения. Название, наличие и поведение античита этим тестом не устанавливаются.

Скрипт подготовлен под AHK v2. Выполнение и проверка синтаксиса интерпретатором на Windows здесь недоступны; реальный запуск ещё не подтверждён. Проверены содержимое архива и ограничение скрипта одной парой F2 с отпусканием в finally. Драйверы и изменения защиты системы не требуются.
